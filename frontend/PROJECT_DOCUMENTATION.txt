1. PROJECT OVERVIEW & EXECUTIVE SUMMARY
====================================================================================================

1.1 Executive Summary
---------------------
Project KEYSTONE is an enterprise-grade, end-to-end Field Service Management (FSM) platform engineered 
to bridge the operational gap between field technicians, dispatchers, customers, and executive management. 
The platform streamlines the entire lifecycle of field service requests—from initial public enquiry and 
quote estimation to work order creation, real-time technician dispatching, labor and spare parts tracking, 
SLA compliance enforcement, and automated reporting.

Built with performance, security, and responsive user experience at its core, KEYSTONE features a 
high-conversion modern landing page powered by GSAP animations alongside a multi-role web application 
providing tailored user interfaces based on granular Role-Based Access Control (RBAC).


1.2 Core Business Objectives & Value Proposition
------------------------------------------------
- Operational Efficiency: Eliminates manual paper-based dispatching and spreadsheet tracking by digitizing 
  the complete service lifecycle.
- SLA Compliance & Accountability: Automatically tracks Service Level Agreement (SLA) deadlines per ticket, 
  flagging overdue work orders and calculating real-time SLA compliance rates.
- Resource & Inventory Control: Provides real-time visibility into field inventory, tracking spare part consumption 
  per work order and maintaining precise stock counts.
- Dynamic Role-Based Experience: Delivers role-tailored dashboards for Managers, Dispatchers, Field Technicians, 
  and Customers, ensuring every persona has access to exact workflows without clutter.
- Customer Empowerment: Offers a self-service customer portal for service requests, order tracking, and 
  location updating, driving customer satisfaction and reducing call-center friction.


1.3 User Personas & Role-Based Access Control (RBAC)
---------------------------------------------------
KEYSTONE enforces 4 distinct system roles, each mapped to specific security scopes:

1. MANAGER (Executive Administrator):
   - Full administrative control across the platform.
   - Access to executive analytics (SLA compliance, technician performance, site breakdown).
   - Customer and site management (create, update, delete customers/sites).
   - Work order deletion and full lifecycle override capability.
   - Inventory tracking and incoming customer quote enquiry management.

2. DISPATCHER (Operations Specialist):
   - Operations-focused role responsible for job scheduling and technician dispatch.
   - Access to visual Kanban Dispatch Board for status transitions and job drag-and-drop workflow.
   - Work order creation, editing, technician assignment, and customer management.
   - Review and management of incoming public service enquiries.

3. TECHNICIAN (Field Operative):
   - Mobile-optimized workstation focused strictly on assigned work orders ("My Active Jobs").
   - One-click job status transitions (Start Job -> In Progress -> Pause -> Complete Job).
   - Labor time clocking (logging minutes worked with technician notes).
   - Inventory consumption logging (selecting spare parts used and recording quantities).

4. CUSTOMER (Client / Site Owner):
   - Portal tailored for end-customers to request field service jobs.
   - View history of submitted work orders, current status, assigned technician, and SLA target dates.
   - Site profile view with capability to update live address/GPS coordinates for service teams.

2. TECHNOLOGY STACK SPECIFICATIONS
====================================================================================================

2.1 Frontend Architecture (Client Application)
----------------------------------------------
- Core Framework: React 19 (TypeScript 6)
- Build System & Dev Server: Vite 8.1
- Single Page Application (SPA) Router: React Router DOM v7.18
- UI Styling: Custom Vanilla CSS with CSS Custom Properties (Design System tokens, glassmorphism, 
  dark mode aesthetics, responsive flex/grid)
- Micro-Animations & Interactivity:
  * GSAP (GreenSock Animation Platform) 3.15 with ScrollTrigger & CustomEase
  * Custom text typing engine (TextType.tsx) and character splitting animations (SplitText.tsx)
- Iconography: Lucide React (lucide-react 1.24)
- State Management: React Context API (AuthContext) with persistent browser LocalStorage fallback
- Code Quality & Linting: Oxlint (oxlint 1.71)

2.2 Backend Architecture (Server Application)
----------------------------------------------
- Runtime & Language: Java 20 (Java OpenJDK)
- Framework: Spring Boot 3.2.5 (Starter Web, Data JPA, Security, Validation)
- Authentication & Authorization:
  * Spring Security 6 with Stateless JWT Token Filter
  * Java JWT (jjwt 0.11.5) with 256-bit HS256 encryption
  * BCrypt password hashing encoder ($2a$10$)
- Database ORM / Persistence: Spring Data JPA + Hibernate ORM
- Database Migration Engine: Flyway DB (10.11.0) with automated SQL versioned scripts (V1__init_schema.sql to V6)
- API Specification & Documentation: OpenAPI 3.0 / Swagger UI (springdoc-openapi-starter-webmvc-ui 2.5.0)
- Productivity Utilities: Lombok (Lombok annotations for DTOs, Builders, Entities)

2.3 Database Layer
------------------
- Database Engine: PostgreSQL 15+
- Driver: PostgreSQL JDBC Driver (org.postgresql:postgresql)
- Object-Relational Model:
  * UUID primary keys across all relational entities for secure global uniqueness.
  * Referential integrity enforced with cascading & set-null constraints.
  * Check constraints on inventory stock, logged minutes, and part quantities.

2.4 Infrastructure & Cloud Deployment
-------------------------------------
- Frontend Hosting: Vercel SPA Hosting with automated API rewrites (`/api/*` -> Render backend)
- Backend Hosting: Render Web Service (Docker container deployment via backend/Dockerfile)
- Production Database: Render Managed PostgreSQL (`keystone-db`)

5. REST API SPECIFICATIONS & ENDPOINTS
====================================================================================================

5.1 Authentication Controller (`/api/auth`)
- `POST /api/auth/login`: Authenticate user credentials and return JWT bearer token.
- `POST /api/auth/register`: Public registration endpoint for new customer account creation.

5.2 Work Order Controller (`/api/work-orders`)
- `GET /api/work-orders`: Paginated list of work orders with multi-column sorting and status filters.
- `GET /api/work-orders/{id}`: Detailed work order object with time logs, parts used, and status history.
- `POST /api/work-orders`: Create new work order ticket (Secured: Manager, Dispatcher, Customer).
- `PUT /api/work-orders/{id}`: Edit work order attributes.
- `POST /api/work-orders/{id}/assign`: Assign or reassign technician to a job.
- `POST /api/work-orders/{id}/status`: Execute status transitions (NEW -> ASSIGNED -> IN_PROGRESS, etc.).
- `POST /api/work-orders/{id}/parts`: Log inventory part consumption for work order.
- `POST /api/work-orders/{id}/time`: Log labor time minutes and field notes.
- `GET /api/work-orders/technicians`: Retrieve available technician user list (Secured: Manager, Dispatcher).
- `DELETE /api/work-orders/{id}`: Permanently remove work order (Secured: Manager).

5.3 Customer & Site Controller (`/api/customers`, `/api/sites`)
- `GET /api/customers`: Search and list customer profiles.
- `POST /api/customers`: Create customer organization profile.
- `GET /api/customers/{id}/sites`: List sites registered to customer.
- `POST /api/customers/{id}/sites`: Add new physical site/facility to customer.
- `GET /api/sites`: Global list of sites for dropdowns.

5.4 Parts & Inventory Controller (`/api/parts`)
- `GET /api/parts`: Retrieve active parts inventory with SKU, stock quantity, and unit cost.

5.5 Public Enquiry Controller (`/api/enquiries`)
- `POST /api/enquiries`: Submit public landing page quote request/enquiry.
- `GET /api/enquiries`: List enquiries for management review (Secured: Manager, Dispatcher).
- `PATCH /api/enquiries/{id}/read`: Mark enquiry status as READ.

5.6 Executive Analytics Controller (`/api/reports`)
- `GET /api/reports/summary`: Compute executive dashboard metrics (SLA rate, status counts, technician stats).

6. CONCLUSION & FUTURE ROADMAP
====================================================================================================

6.1 Conclusion
--------------
Project KEYSTONE delivers a production-ready, highly efficient Field Service Management platform that 
combines modern frontend aesthetics (GSAP micro-animations, glassmorphism, responsive role dashboards) 
with a robust enterprise backend architecture (Spring Boot 3, Spring Security, JWT, PostgreSQL, Flyway).

The system successfully resolves key operational challenges in field service management:
1. Complete visibility over technician dispatch and work order SLA metrics.
2. Real-time spare parts stock tracking and labor logging for precise job costing.
3. Decoupled cloud architecture ready for cloud deployment on Vercel and Render.
4. Clean, modular code structure adhering to industry best practices in security and REST API design.

6.2 Recommended Future Enhancements
-------------------------------------
- Real-Time WebSocket Push Notifications: Integrate Spring WebSocket / STOMP for live dispatch updates.
- Native Mobile App Build: Package the React frontend as a progressive web app (PWA) or Capacitor build 
  for offline field technician support.
- Route Optimization API: Integrate Google Maps / OpenStreetMap Routing API to calculate optimal daily 
  driving routes for technicians.
- Automated Invoicing: Integrate Stripe / PayPal billing endpoints to automatically generate client 
  invoices upon work order closure.
